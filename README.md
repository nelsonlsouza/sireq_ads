# SIREQ — Sistema Inteligente de Requisições e Aprovações

MVP web acadêmico em TypeScript para demonstrar cadastro, validação, Fila FIFO, análise, decisões, Pilha LIFO, histórico, desfazimento e persistência em LocalStorage.

## Executar
```bash
npm install
npm run dev
```

## Testar
```bash
npm test
npm run build
```

## Demonstração
Cadastre A, B e C; confirme a ordem FIFO; analise A; registre uma decisão; consulte o histórico LIFO e use "Desfazer última".
